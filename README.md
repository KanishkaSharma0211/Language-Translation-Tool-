# 🌍 Language Translation Tool

A simple and smart web app to translate text between multiple languages, built with **Python** and **Streamlit**.

## 🚀 Features

- 🌐 Supports 17+ languages
- ⚡ Instant translation using Google Translator
- 📥 Download translated text as a file
- 🎯 Simple and clean UI

## 🛠️ Tech Stack

- **Python**
- **Streamlit** - Web UI
- **Deep Translator** - Google Translation API

## 📦 Installation

1. Clone the repository:
```bash
   git clone https://github.com/KanishkaSharma0211/Language-Translation-Tool-.git
   cd Language-Translation-Tool-
```

2. Install dependencies:
```bash
   pip install -r requirements.txt
```

3. Run the app:
```bash
   streamlit run app.py
```

## 🌐 Supported Languages

English, Hindi, French, Spanish, German, Italian, Portuguese, Russian, Chinese, Japanese, Korean, Arabic, Turkish, Dutch, Bengali, Punjabi, Urdu
